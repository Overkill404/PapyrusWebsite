Error! Sans website — setup
===========================

FILES TO ADD YOURSELF:
  bot-avatar.gif     → bot profile GIF (right-click bot in Discord → Save / Copy Image)
  error-sprite.gif   → Error Sans battle sprite (or reuse bot-avatar.gif)
  background.png     → full-page background image (png/jpg/gif)
  favicon.gif        → tab icon (or favicon.ico) — can be a small crop of the bot face

OR edit script.js:
  BOT_AVATAR_URL = "https://cdn.discordapp.com/avatars/....gif?size=256"

OR edit style.css:
  --hero-bg: url("https://your-image-url");

Open index.html in a browser.
